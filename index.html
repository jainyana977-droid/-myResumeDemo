Assignment 7: Identifying APIs for To-Do List App

Objective

Identify and plan necessary RESTful APIs required for a To-Do List Application.

1️⃣ Add Task (CREATE)

Endpoint: POST /api/tasks

Request Body:

{
  "title": "Complete Assignment",
  "description": "Finish API planning task",
  "dueDate": "2026-02-20",
  "status": "pending"
}

Response: 201 Created

Logic: Generate unique ID using UUID or auto-increment ID.

2️⃣ Get All Tasks (READ)

Endpoint: GET /api/tasks

Response: 200 OK

[
  {
    "id": 1,
    "title": "Complete Assignment",
    "status": "pending"
  }
]

3️⃣ Update Task (UPDATE)

Endpoint: PUT /api/tasks/:id

Request Body:

{
  "title": "Complete Assignment",
  "status": "completed"
}

Response: 200 OK

4️⃣ Delete Task (DELETE)

Endpoint: DELETE /api/tasks/:id

Response: 204 No Content

How APIs Fulfill CRUD

  • Create → POST
  • Read → GET
  • Update → PUT
  • Delete → DELETE

Challenges

  • Handling authentication
  • Validating request data
  • Handling errors properly
  • Managing database connections
